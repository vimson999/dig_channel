## 二、对标逻辑假设与方法库变化

**保留的受众/痛点假设：** 受众已经知道 AI、半导体或宏观事件，但需要在回撤或数据窗口前区分“基本面变化”与“估值/资金面波动”。他们需要的不是无条件结论，而是能缩短下一步判断时间的验证框架。

**强化的我方规则：**

1. 标题保持“对象/时点 + 关键分歧 + 可验证下一步”结构；例如“回撤后逻辑变了吗？看三条验证线”。不复制“危机仍在”“主线已转向”等不可证伪的结论承诺。
2. 下载信号继续以绝对量、入库年龄、本地可读、版本一致性和外部时点交叉加权；没有固定“三天有效期”。AI 材料的 +4 与存储材料的高绝对下载只提高候选优先级，不单独构成门槛。
3. **修订重复记录规则：** 文件名相同不等于内容相同。仅当 file ID、topic 与内容哈希均可支持时才允许合并；本轮两条长鑫材料哈希不同，永久取消“同一副本”的假设，并保持独立标识。
4. **转化证伪条件不变：** 获得我方 CTR、收藏、完播或实际付费数据后，若“事件 + 条件验证线”标题不优于基线，或宏观窗口消失、PDF 需求不持续，即下调题材/标题规则；不得用对标播放补证。
