# 研报音频方案三：视觉视频嵌框竖版

## 需求与验收

- 在研报音频工作流增加“方案三：标题框架 + 视觉视频”。
- 关键帧确认只渲染 `thumbnail-workbench.html` 的 `video_bg` 模板，检查机构、主标题、副标题、横屏框和底部品牌，不依赖视觉视频已经完成。
- 10 秒预览和完整成片必须嵌入同一 PDF、当前顶部所选视觉方案的已完成横屏视频。
- 视觉视频不存在、未完成或不属于同一 PDF 时明确拒绝合成，不回退为静态背景。

## 成功经验复用

- 模板：复用封面工作台已验证的 `video_bg` 画布与 1080×1920 尺寸。
- 身份校验：复用研报详情页“同一 PDF 视觉方案视频”的 attachment id / 文件名加字节数校验，不接受客户端文件路径。
- 编排：复用现有 publisher 子任务、预览时长、字幕样式、结果路径和失败收口。
- 前端：复用方案一/二的关键帧确认、10 秒预览、完整成片和下载入口。

## 差异实现

- 新增 `scheme3` 规范化别名和展示标签。
- 新增工作台 `video_bg` 服务端渲染入口。
- 新增 FFmpeg 竖版嵌框合成器：横屏内容固定在模板 `y=620`、宽 `1080`、高 `608` 的 16:9 区域。
- 正式合成请求只传视觉工作流 ID，后端解析受信任的本地视频路径。

## 验证

- Python 与 JavaScript 语法检查。
- API、工作流任务和竖版布局单元测试。
- 实际渲染 1080×1920 关键帧。
- 使用 16:9 测试视频和 WAV 实际合成竖版 MP4，并抽帧检查嵌框位置。
