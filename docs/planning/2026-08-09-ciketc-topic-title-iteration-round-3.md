## 二、对标逻辑假设与证伪

1. **保留并强化：** “变化 + 验证变量”比“来源 + 最快”更适合我方。前者回应决策者的下一步判断，后者主要解决高频信息筛选；二者的相对转化效果尚无我方 CTR/留存数据，不能比较优劣。
2. **新增：** 宏观/配置题在早期数据中得到跨账号出现的弱支持。若到 24h/72h，黄金与 Risk-on 的增量明显低于相近时龄行业稿，或评论并未讨论配置变量，则撤回“宏观解释有额外需求”的假设。
3. **保留反例：** 电子布 1,146 播但原始 PDF 缺位。A、C 同向无法替代 B；此条仍不纳入执行候选。
4. **下载信号规则不变：** 本轮存储下载略增（59/67/64），但只有两轮静态累计值，不能称为需求日增，也不能形成统一的三天有效期。

## 三、方法库的具体变化

在第二轮七因子框架与“同龄记录、素材缺口”规则上，新增两项：

- **标题承诺匹配规则：** 当 PDF 只能确认文件存在、无法可靠抽取/核验正文时，标题只能承诺“验证什么 / 哪种情景成立”，不得承诺目标价、供需结论或单一事件的因果。审稿时逐页确认后才能升级为结论式标题。
- **跨题材同龄对照规则：** 每轮记录新宏观、产业、公司题在 6h/24h/72h 的播放、评论、弹幕；同龄对照只生成假设，不直接给题材打分。必须结合 PDF 可用性与市场事件窗口，才可进入排序。

框架其余构成保持可追溯：受众/痛点假设、原始素材筛选、下载需求、时效与差异化、市场关注验证、价值主张、标题结构、预期转化信号与证伪条件。
