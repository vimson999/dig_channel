# 开发进度报告 - 2026-03-19

## 🚀 今日突破：多屏并行产出与交互精度提升

今日完成了视频生产流水线的深度升级，核心解决了“多端分发效率”与“预览交互精度”两大痛点。

### 1. 新增功能
- **预览区自由变换**：横屏封面与视频预览区支持鼠标拖拽（Drag）与滚轮缩放（Zoom），并新增了浮动控制按钮。
- **并行双竖屏流**：支持一键同时生成主竖屏（精修封面版）与备选竖屏（纯底图版），大幅减少重复操作。
- **ASR 模型升级**：默认使用 Large-v3 引擎，并注入了金融专用词库 Prompt，显著提升了研报类视频的字幕准确度。

### 2. 性能与逻辑优化
- **智能渲染模式**：竖屏视频引入 `Contain` 模式，确保上传的研报截图/表格原始比例完整展示，不再被暴力裁剪。
- **多音频对齐修复**：重构了全局字幕偏移计算逻辑，解决了多段音频拼接时 `audio_start` 导致的字幕累计错位 Bug。
- **字号位置定稿**：
    - 横屏：Font 20, MarginV 38 (精致电影感)
    - 竖屏1：MarginV 198 (贴合副标题)
    - 竖屏2：MarginV 205 (底图展示优先)
