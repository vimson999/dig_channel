# 项目状态更新记录 - 2026-01-16

**记录时间**: 2026年1月16日 11:55
**当前分支**: 0116-test-tts

## 1. 数据库架构升级 (核心)
- **全面切换至 PostgreSQL**: 
    - 移除了所有模块对 SQLite 的硬编码依赖。
    - 强制 `src/backend/config/base.py` 使用环境变量构建 PG 连接串。
    - 优化了 `init_db.py` 中的视图定义，使其兼容 PostgreSQL 语法 (CURRENT_DATE, INTERVAL, Boolean)。
    - 测试服务器 `test_server.py` 已同步至新配置。

## 2. TTS 语音合成模块升级
- **环境修复**: 解决了 `numpy 2.x` 与 `coqui-tts/pandas` 的二进制不兼容问题，将 `numpy` 降级至 `<2 (1.26.4)`。
- **配置启用**: 在 `.env` 和代码中默认启用了 `ENABLE_TTS_API`。
- **模型升级**: 
    - 引入了 **YourTTS (VITS)** 模型代替旧的 Tacotron2。
    - 实现了原生多说话人支持，优化了角色映射逻辑。
- **健壮性修复**: 增加了模型语言自动检测与回退逻辑，解决了 `zh-cn` 不在 YourTTS 默认语言列表中导致的崩溃问题。

## 3. 下一步计划
- **模型优化**: 考虑集成 GPT-SoVITS 或 ChatTTS 以获取更自然的中文对话效果。
- **功能验证**: 在 0116-test-tts 分支上持续测试多人对话的音质表现。
