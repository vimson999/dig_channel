# 开发进度报告 - 2026-03-18

## 🚀 今日突破：视频生产流水线性能革命

今日完成了“阶段一：性能深度优化”，通过引入 **FFmpeg Direct 直接合成引擎** 和 **ASR 模型热切换**，实现了视频生产效率的数倍提升。

### 1. 性能量化指标 (基于 35s 测试音频)
- **总耗时**：从 **170s** 缩短至 **29s** (Tiny 模型) / **42s** (Large-v3 模型)。
- **渲染效率**：提升了 **5.8 倍**。
- **ASR 速度**：识别 35s 音频仅需 **12s** (Tiny) / **17s** (Large-v3)。

### 2. 核心功能更新
- **ASR 模型热切换**：
    - 后端 `ASRService` 支持动态加载 `tiny` 到 `large-v3` 不同尺寸模型。
    - 前端 `publisher.html` 增加模型选择下拉框，支持“速度优先”与“精度优先”切换。
- **FFmpeg Direct 合成引擎**：
    - 弃用 `MoviePy` 逐帧处理模式，改用原生 FFmpeg 滤镜链。
    - 实现了 **SRT 字幕硬件级烧录** (利用 `subtitles` 滤镜)。
    - 强制开启 **Apple Silicon 硬件加速** (`h264_videotoolbox`)。
- **系统稳定性修复**：
    - **Celery 兼容性**：将 Worker 启动模式切换为 `-P threads`，彻底解决了 Mac M 系列芯片上 Metal GPU 驱动在多进程模式下崩溃的 Bug。
    - **封面生成**：修复了 `date_text` 为空时导致封面合成中断的 `NoneType` 错误。
