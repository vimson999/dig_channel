## 写入导演包与评审的强制规则

1. `RFL-01`：每段必须写明 `shot_intent`，素材类型不能代替镜头意图。
2. `RFL-02`：解释机制时优先对象、动作、箭头和逐层揭示；一张图只承担一个因果动作。
3. `RFL-03`：转场只可表达证据→解释、局部→系统、现在→风险等语义变化；禁止纯装饰性转场。
4. `RFL-04`：数据按“比较/异常 → 机制 → PDF 证据”排列；PDF 仍按全页→推近→遮暗→重绘执行。
5. `RFL-05`：连续三段不得复用同一素材语法；风险/反转要以视觉对比形成记忆点，不能只用红色卡片。
6. 观众画面仍禁止 `evidence`、`editor`、任务、审批、素材类型等制作元数据；来源仅限证据镜头的中文化短署名。

## 当前落地

`report_video_director.py` 将本库版本、规则 ID、每段 `shot_intent` 和语义转场契约写入导演包，并在校验中失败关闭；单元测试覆盖缺失镜头意图的拒绝路径。低成本真实 PDF 预览的 manifest 会保存这份导演包，因此可对比旧版的素材计划和新版的“意图—规则—素材”链路。
