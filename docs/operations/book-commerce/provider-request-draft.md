# 向数据提供方索取首批 JSON 的消息草稿

> 这是待转发文本，不会自动发送。确定对接人和沟通渠道后，可附上同目录的 `import-contract.md` 与 `sample-import.json`。

你好，我们已经完成内部“视频号图书带货情报”导入和分析模块。请先按随附的 JSON 约定提供一份小批量样例，暂不需要开发接口或自动采集。

请优先包含：

1. 2–3 个账号的稳定标识、名称及可提供的账号基础信息。
2. 每个账号下 2–3 个图书商品；书籍 ISBN（如有）、店铺商品标识、商品名称、商品与标准书籍的对应关系。
3. 每个账号 2–5 条视频；稳定视频标识、标题、发布时间、可公开查看的链接；如果能合法提供，再附字幕/逐字稿。
4. 视频是否实际挂载商品的证据、关系起止时间和证据链接。无法确认时请标记为 `unverified`，不要推测。
5. 至少两个相邻日期的账号、商品和视频累计观测值，附每条记录的实际采集时间与时区。请提供累计销量、点赞、转发等原值，不要自行计算日增量；对约数、下限或未采集值按合同填写质量标记。

请将这些内容整理为一个 UTF-8 `.json` 文件，保持 `source_key` 在后续批次中稳定，所有引用可互相解析。先不用传 Cookie、账号密码、访问令牌或含凭据的链接。样例数据需要经过授权；如需脱敏，请保留字段结构、跨行引用和时间间隔，以便我们验证。

收到后我们会先在系统中预览并反馈格式或关联问题；确认无误后再决定是否导入正式数据。请同时说明数据来源、可提供的字段、观测时间定义、更新频率和任何精度限制。
