# YouTube频道数据追踪工具 - 产品需求文档 (PRD)

## 📋 产品概述

### 产品定位
为YouTube创作者设计的专业频道数据追踪和分析工具，通过自动化数据抓取、可视化展示和趋势分析，帮助创作者进行日常运营监控和数据决策。

### 目标用户
- **主要用户**：YouTube创作者
- **使用场景**：日常运营监控
- **核心需求**：同时追踪10个或更多频道的数据变化

### 产品价值
- 自动化数据收集，节省手动统计时间
- 直观的数据可视化，快速洞察趋势
- 多频道对比分析，优化内容策略
- 收入预估功能，辅助商业决策
- 排行榜功能，实时了解各频道表现

## 🎯 核心功能

### 1. 排行榜展示（新增核心功能）
**4个排行榜卡片**：
- **日收入排行榜**：显示当日各频道预估收入排名
- **月收入排行榜**：显示本月各频道累计收入排名
- **日新增订阅排行榜**：显示当日各频道订阅增长排名
- **月新增订阅排行榜**：显示本月各频道订阅增长排名

**排行榜特性**：
- 实时数据更新
- 前3名突出显示
- 支持金额和数量格式化显示
- 每个卡片显示Top 3频道

### 2. 频道管理
- **添加频道**：通过YouTube频道URL或ID添加追踪频道
- **CPM设置**：每个频道独立设置CPM值用于收入计算
- **频道分类**：支持可选的分类标签管理
- **频道删除**：移除不再需要追踪的频道

### 3. 数据抓取与存储
- **自动抓取**：系统每日定时自动抓取频道数据
- **数据持久化**：所有历史数据永久保存，不删除
- **增量计算**：自动计算较前日的增长数据
- **收入估算**：根据浏览量增量 × CPM自动计算预估收入

### 4. 数据展示 - 核心大表格
**表格结构设计**：
- **纵轴**：日期（最新日期在顶部）
- **横轴**：频道数据（可水平滚动）
- **双行表头**：
  - 第一行：频道名称 + CPM值
  - 第二行：7个数据列标题

**每个频道的7列数据**：
1. **当天订阅数** - 当日订阅总数
2. **当天总浏览量** - 当日总浏览量
3. **当天视频总量** - 当日视频总数
4. **较昨天新增订阅数** - 订阅增长量
5. **较昨天浏览量增量** - 浏览量增长
6. **较昨天视频数增量** - 新发布视频数
7. **当日预估收入** - 浏览量增量 × CPM

**表格特性**：
- 冻结首行（表头）和首列（日期）
- 今日数据行高亮显示
- 正负增长用不同颜色标识
- 表格随频道数量向右扩展
- 预估收入列突出显示

### 5. 数据可视化
**图表类型**：
- **订阅增长趋势图**：展示各频道订阅增长趋势
- **浏览量趋势图**：展示各频道浏览量变化
- **收入趋势图**：展示各频道预估收入趋势

**图表功能**：
- 支持多频道对比
- 平滑线图展示
- 交互式图例
- 时间范围筛选（7天/30天/90天/自定义）

### 6. 操作界面
**顶部操作栏**：
- 左侧：添加频道按钮 + 默认CPM设置
- 右侧：图表类型切换 + 时间筛选 + 数据刷新

**模态框功能**：
- 新增频道表单

- 分类标签选择

### 数据模型
```sql
-- 频道表
CREATE TABLE channels (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100) NOT NULL,
    url VARCHAR(255) NOT NULL,
    cpm DECIMAL(5,2) NOT NULL,
    category VARCHAR(50),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 频道数据表
CREATE TABLE channel_data (
    id INT PRIMARY KEY AUTO_INCREMENT,
    channel_id INT NOT NULL,
    date DATE NOT NULL,
    subscribers INT NOT NULL,
    total_views BIGINT NOT NULL,
    video_count INT NOT NULL,
    subscriber_change INT DEFAULT 0,
    view_change INT DEFAULT 0,
    video_change INT DEFAULT 0,
    estimated_revenue DECIMAL(10,2) DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (channel_id) REFERENCES channels(id),
    UNIQUE KEY unique_channel_date (channel_id, date)
);

-- 排行榜视图
CREATE VIEW daily_revenue_ranking AS
SELECT 
    c.name,
    cd.estimated_revenue,
    ROW_NUMBER() OVER (ORDER BY cd.estimated_revenue DESC) as rank
FROM channels c
JOIN channel_data cd ON c.id = cd.channel_id
WHERE cd.date = CURDATE();

CREATE VIEW monthly_revenue_ranking AS
SELECT 
    c.name,
    SUM(cd.estimated_revenue) as total_revenue,
    ROW_NUMBER() OVER (ORDER BY SUM(cd.estimated_revenue) DESC) as rank
FROM channels c
JOIN channel_data cd ON c.id = cd.channel_id
WHERE cd.date >= DATE_SUB(CURDATE(), INTERVAL 30 DAY)
GROUP BY c.id, c.name;

CREATE VIEW daily_subscriber_ranking AS
SELECT 
    c.name,
    cd.subscriber_change,
    ROW_NUMBER() OVER (ORDER BY cd.subscriber_change DESC) as rank
FROM channels c
JOIN channel_data cd ON c.id = cd.channel_id
WHERE cd.date = CURDATE();

CREATE VIEW monthly_subscriber_ranking AS
SELECT 
    c.name,
    SUM(cd.subscriber_change) as total_subscriber_change,
    ROW_NUMBER() OVER (ORDER BY SUM(cd.subscriber_change) DESC) as rank
FROM channels c
JOIN channel_data cd ON c.id = cd.channel_id
WHERE cd.date >= DATE_SUB(CURDATE(), INTERVAL 30 DAY)
GROUP BY c.id, c.name;
```

### 核心算法
```javascript
// 增量计算逻辑
function calculateDailyChanges(todayData, yesterdayData) {
    return {
        subscriber_change: todayData.subscribers - yesterdayData.subscribers,
        view_change: todayData.total_views - yesterdayData.total_views,
        video_change: todayData.video_count - yesterdayData.video_count,
        estimated_revenue: (todayData.total_views - yesterdayData.total_views) * channel.cpm / 1000
    };
}

// 排行榜数据计算
function calculateRankings(channels, timeframe = 'daily') {
    const rankings = {
        revenue: [],
        subscribers: []
    };
    
    channels.forEach(channel => {
        const data = getChannelData(channel.id, timeframe);
        rankings.revenue.push({
            name: channel.name,
            value: timeframe === 'daily' ? data.estimated_revenue : data.total_revenue
        });
        rankings.subscribers.push({
            name: channel.name,
            value: timeframe === 'daily' ? data.subscriber_change : data.total_subscriber_change
        });
    });
    
    // 按数值降序排序
    rankings.revenue.sort((a, b) => b.value - a.value);
    rankings.subscribers.sort((a, b) => b.value - a.value);
    
    return rankings;
}
```
