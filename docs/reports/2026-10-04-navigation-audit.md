# 系统导航梳理与调整建议

日期：2026-10-04。范围：统一导航、菜单目标页面和桌面导航交互。状态：仅梳理与建议，未修改业务导航。

后续状态：用户确认继续后，导航重分组与交互修复已实施，见 [统一导航升级验收](2026-10-04-navigation-upgrade.md)。下文保留改造前清单与证据；功能搜索和业务页面合并未纳入本轮。

## 结论

系统已从数据分析扩展成「内容情报 → 素材 → 制作 → 发布 → 运维」平台，但导航仍按开发时逐步追加功能的方式组织。

当前有 6 个一级栏目、54 个不同的目标入口（含首页）：数据中心 4、选题洞察 8、生产发布 5、AI创作 17、工具箱 19，另有首页 1。AI创作与工具箱占 36/54，约三分之二。

54 个入口 URL 没有重复；53 个站内目标文件均存在，另 1 个是本机 5005 端口的外部批量任务台。文件存在不代表功能已经通过运行验收，也不能仅凭名称相近认定功能重复。

建议保留全部功能与原 URL，优先解决分类、命名、菜单可达性；不删除旧版、不改变首页 Top 10、不修改采集与发布逻辑。

## 二、体验检查：问题与证据

### 1. 展开工具箱：部分入口超出窗口

严重度：高。1280×720 桌面窗口实测，菜单顶部 y=64、底部 y=766、高度 702px，容器 overflow 为 visible，缺少菜单内部滚动。截图中「研报 PDF Gem」已不在窗口可见范围，「Gemini 调试」靠近底边。

建议使用有分组标题的宽面板；按窗口高度约束并支持内部滚动。菜单不能靠无限纵向追加入口维持扩展。

![工具箱菜单超出窗口底部](/Users/v9/.codex/visualizations/2026/09/30/01a0efc3-1a82-7422-ba3b-f4da758a4219/navigation-tools-audit.jpg)

### 2. 展开 AI创作：功能多，但缺少任务分组

严重度：中。17 个入口连续排列，单段转写、批量转写、研报编排、视频制作、封面、测试入口并列。菜单高 630px。

归类边界也不一致：高级剪辑在生产发布、PDF 滚动视频在工具箱，其余视频生成在 AI创作；素材下载放在生产发布；运维与凭据夹在文档工具之间。

建议按「音频与文字／研报制作／视频制作／封面设计」分组，测试功能独立标识。

![AI创作菜单没有功能分组](/Users/v9/.codex/visualizations/2026/09/30/01a0efc3-1a82-7422-ba3b-f4da758a4219/navigation-ai-audit.jpg)

### 3. 键盘展开：当前不可用

严重度：高。鼠标移开菜单后，将焦点放在 AI创作按钮并按 Enter，实测按钮已聚焦，但面板 visibility 仍为 hidden；没有 aria-expanded。源代码依赖 group-hover 显示菜单，桌面菜单没有对应的展开事件。

建议补齐点击、Enter/Space 展开，Esc 关闭、焦点返回、当前页 aria-current、展开状态 aria-expanded，并保留鼠标操作。移动菜单源码是所有分组直接展开，建议后续验证并改为可折叠分组；本轮没有实测移动设备。

### 4. 进入 Celery 控制台：当前位置错误

严重度：中。进入 `celery-monitor.html` 后导航仍将首页显示为当前项。静态执行页面识别方法也确认：期望 `celery-monitor`，实际返回 `dashboard`。该路由遗漏在页面识别表中，未知页面默认回退首页掩盖了遗漏。

建议以单一导航配置统一生成菜单、页面名称、面包屑和当前项，避免维护多份互不一致的映射。

![Celery 页面仍标记首页为当前导航](/Users/v9/.codex/visualizations/2026/09/30/01a0efc3-1a82-7422-ba3b-f4da758a4219/navigation-celery-audit.jpg)

### 5. 命名与辅助入口：有误导或占位

严重度：中。

- 「音频转文案」页面实际描述的是目录批量转写，不是文案改写；建议叫「批量音频转写」，与「音频转文字」区分单文件／目录批量。
- 「研报转火柴人视频」页面已描述通用视觉方案，名称窄于页面能力；建议叫「研报视觉视频」。
- 「研报 Top10」页面标题为「今日研报严选编排台」，说明支持 N 份研报；建议「研报严选（Top10）」保留熟悉称呼并解释实际用途。这不涉及首页 Top 10 数量。
- 「清单分析与历史」缺少对象，建议「星球清单分析」；历史作为页面内标签。
- 「完整排行榜」建议「频道排行榜」，比“完整”更清楚地说明排行对象。
- 右上角设置、帮助在共享导航组件中没有绑定业务动作；本次点击设置未发生可见变化。「个人资料」「账户设置」使用 `href="#"`。应接真实入口或明确暂不可用，不能让占位项看起来已实现。
- 批量任务台明确标记为外部链接，但依赖本机 5005 服务；建议补充服务状态和无法访问时的说明。此次没有验证该独立服务。

## 三、建议导航结构

维持 6 个业务一级栏目，不增加整排菜单按钮；用现有齿轮承接系统管理。以下是分类建议，不是已实施变更。

```text
数据与素材                   6
  频道管理 / 视频库 / 频道排行榜 / 我的收藏
  素材下载 / 网页内容投递
选题情报                     7
  爆款搜索 / 趋势雷达 / 商机发现 / B站情报台
  星球情报：生财情报台 / 星球清单分析 / 知识星球内容分析
内容制作                    17
  音频与文字：音频转文字 / 批量音频转写 / 语音合成
  研报制作：基础文案 / 转语音 / 导图视频 / 视觉视频 / 研报严选（Top10）
  视频制作：AI 视频合成 / 文案到成片 / MP3 视频编排
            播客视觉化 / 高级剪辑 / PDF 滚动视频

  文档处理：PDF 工具平台 / PDF 合并 / 文档转换
            Word 转长图 / MHTML 转 PDF / PDF 去水印

  实验室：网页朗读测试 / 研报视觉编排 / 抖音上传测试
          视频号投递测试 / Gemini 调试 / 研报 PDF Gem
  旧版工具：通用封面旧版 / 经典封面旧版

  任务队列（Celery）/ 平台凭据 / 星球 API 调用方 / 历史文件清理
```

合计仍为 54 个入口，无删除、无 URL 迁移。分组标题不是新增功能页面。实验室建议基于当前界面中的“测试／调试”标识；不能仅因文件名含 `test` 就把日常使用的研报流程移走，正式/实验状态实施前需核对。若研报视觉编排已是日常正式流程，可留在研报制作组并移除测试表述。

知识星球的几页不建议立即合并：情报发现、清单元数据分析、本地内容覆盖、任务策略分别解决不同问题。PDF 工具平台与 PDF 合并也是不同入口，不应只看名字就删除其中之一。

“内容制作”比“AI创作”覆盖更准确，因为编辑、转写、封面等工具不需要用户先判断是否由 AI 驱动。“发布与任务”也明确保留非发布类任务，而不把它们全部叫作发布。

## 四、落地顺序与验收建议

1. **修正可达性与定位**：菜单高度、键盘展开、当前页识别；处理设置和帮助占位。所有现有入口仍可到达。
2. **重分组并统一命名**：使用上面的分类；同步菜单、页面标题、面包屑；保留熟悉称呼作为说明或别名。
3. **增加快速查找**：提供“搜索功能”，匹配当前名称与旧名称；常用/最近入口作为补充，不代替完整菜单。
4. **后续再做工作台整合**：研报入口集中、文案到视频的前后步骤互链。功能合并属于更大范围，需要独立确认，不纳入单纯导航调整。

建议验收：54 个目标不丢失；53 个站内 URL 保持不变；外部工具有标记；桌面短窗口与手机菜单均可访问所有入口；键盘可展开、选择、关闭；每个目标页面的当前项准确；导航可见性不能替代后端权限控制；不触发发布、删除、重启或凭据修改。

## 五、检查边界

依据：`src/frontend/js/shared-navigation.js` 的完整菜单、目标文件存在性与标题检查、相关页面的用途文案，以及本次内置浏览器 1280×720 截图、DOM 几何和键盘检查。

本轮没有逐一执行 54 个业务流程，没有提交任务、发布内容、清理文件或重启服务；没有验证外部 5005 服务、真实移动设备或读屏器，也没有认证/权限审计。因此上述结果是导航信息架构与局部交互审查，不是整个系统的可用性或安全验收。

产品体验审查方法促使本报告把“功能归类”与“入口可达性”分开，并给实测问题附证据；仅新增本文档，未调整现有功能。
