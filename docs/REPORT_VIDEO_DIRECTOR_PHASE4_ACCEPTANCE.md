# 研报视频导演总控：阶段一至四与观众质量验收

日期：2026-07-30

## 结论与历史基线纠正

2026-07-29 的 v4 三份视频只证明了真实内容链路和技术合成可运行，不构成质量验收。其画面含制作/审计语言、三状态重复模板、证据展示可读性不足，按观众视角仅约 30–40/100；原文中的“最终验收通过”结论在此撤销。

v9/v8/v8 虽然清除了主要制作元数据并改善了证据可读性，但用户完整观看后确认其仍是“高级财经 PPT”，缺少连续镜头意图、注意力调度、叙事高潮和足够的非卡片动态画面。原 84/86/84 与“可发布”结论随即撤销；该批次观众质量基线为约 6.5–7/10。

随后完成观众向重构并逐份判退、修复、重渲染。当前最终候选为高盛 v13、伯恩斯坦 v10、摩根士丹利 v10。三份均通过六维观众审片和完整解码，达到数字财经栏目的发布基础线；`premium_editorial_line=false`，原因是仍未使用外部实拍 B-roll、逐条定制 3D 或人工精修动态图形。所有视频仍为隔离测试产物，没有发布，也没有修改生产任务。

## 系统化建设范围

- 阶段一：复用选题池、Gemini 文案/标题/证据、真实配音、PDF 渲染、字幕和 FFmpeg 合成；新增混合媒介导演包、关键帧、代表试映与完整隔离渲染。
- 阶段二：逐条绑定 PDF/page/quote hash，复用整篇音频 ASR 连续时间线，形成 PDF、图表、逻辑卡、风险解释等素材计划。
- 阶段三：导演包可转换为 HyperFrames clip/track 规范；真实高盛开场通过 HyperFrames 0.7.83 的 lint、runtime、layout、motion、contrast 和 frame-check，并作为 15 秒动态视觉 hook 接入现有 FFmpeg 全片合成。
- 阶段四：正式 Flask API 与工作流已接入。测试模式仅允许 `test:` 任务、隔离目录、禁发布、禁改生产任务；生产模式必须由人工批准当前 package hash，缺失或过期批准时失败关闭。

## Production metadata 与观众文案隔离

导演包现在显式区分：

- `production_metadata`：`visibility=manifest_only`、`must_not_render=true`，包含素材类型、任务、状态、审批、证据 ID 等内部字段。
- `audience_copy`：仅允许栏目化中文文案；来源只允许在关键证据镜头短暂显示为“来源：机构研报，第 N 页”。

渲染层不再读取 `media.purpose` 作为画面标题。观众画面禁止 `evidence`、`PDF evidence`、`editor`、`director`、`preview`、`detail`、任务、状态、审批和素材类型等制作语言；发现即拒绝渲染。

## 失败与迭代记录

1. v4 技术跑通但观众质量仅 30–40 分：撤销质量通过结论。
2. 修复观众画面中的 `evidence/PDF evidence/editor` 等后台标签，并加入 fail-closed 文案审计。
3. 发现中文“展示原始证据块”等 `media.purpose` 仍泄漏：彻底切断该内部字段，改为从真实口播生成内容标题。
4. 将每段从三状态扩为五状态，加入精确证据裁切、对象视觉构建/落点、压缩判断卡、章节卡和轻微推镜；非卡片镜头间隔不超过 30 秒。
5. 并行完整渲染曾在 FFmpeg xfade+motion 阶段超时；真实 PDF、音频和帧均已返回。改为顺序渲染并调整 motion 专用超时后，三份均完成。
6. 高盛 v10 发现 HyperFrames 内嵌字幕与总控字幕重复；拆分职责后由总控统一渲染字幕。
7. 高盛 v11 发现单字字幕、长卡片和普通柱图式高潮；改为 ASR 边界吸附的完整语义短句、单行判断卡和 30% 长期低位独立高潮。
8. 高盛 v12 发现 YUV 色键留下亮绿字幕底；改用 RGBA/qtrle 透明字幕轨，v13 复核无绿底。
9. 伯恩斯坦 v9 发现接口芯片误套通用 AI 基础设施三件套、49% 收入占比被误解为长期低位；增加存储接口对象链与竞争壁垒高潮，v10 复核通过。
10. 摩根士丹利 v9 发现 55 美元收入与 5 美元成本柱高画反、杰文斯悖论高潮过于泛化；修正数据方向并重做需求反转高潮，v10 复核通过。
11. 三份最终版重新抽取开场、全片、证据序列、高潮和章节转场检查；未发现制作界面泄漏、黑帧、字幕越界、错误来源页或持续性转场重影。
