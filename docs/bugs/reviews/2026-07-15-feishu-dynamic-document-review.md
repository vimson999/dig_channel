# 2026-07-15 飞书动态文档抓取复发回顾

## 回顾范围

- 时间范围：2026-07-14 至 2026-07-15。
- 触发原因：`FEISHU-DYNAMIC-DOCUMENT-EXTRACTION` 出现第二次；同时上次正式回顾后新增 Bug 已达到提前回顾阈值。
- 重点记录：飞书 Docs 首页误存、飞书合法动态文档误报 Cookie 失效。

## 核心结论

第一次修复只补了“拒绝假正文”，没有补上“如何取得动态真正文”。因此同一个 `Docs` 壳层信号既能表示未登录/首页，也能表示合法文档尚未执行 JavaScript。把技术响应类型直接映射成认证错误，造成了第二次用户可见故障。

## 横向检查

- 飞书外链目前是唯一进入 `external_documents` 抓取链路的平台。
- 知识星球自身 URL 不由 `provider_for_url()` 接受，不会误进入飞书抓取器。
- 静态飞书正文仍保留 HTTP 快速路径；动态 Wiki 使用共享浏览器回退。
- 凭证结构校验仍只表示字段可解析，不作为在线认证成功证明。

## 共享防线

- 壳层检测与正文真实性校验共享同一判定函数。
- 动态壳层必须进入浏览器渲染回退，不得直接标记凭证失效。
- 浏览器路径按正文 block 标识去重，并为虚拟滚动文档持续收集。
- 运行结果记录 extractor、block 数、初始标题与最终 URL。
- 契约测试覆盖静态正文、动态壳层和混合平台链接三个入口。

## 风险与边界

- Cookie 浏览器抓取依赖飞书 DOM，平台改版后可能需要更新选择器。
- 浏览器回退比静态请求慢，应继续只在检测到壳层时启动。
- 图片、表格复杂结构当前投影为可见文本；若后续要求结构化保真，应切换飞书官方 API。

## 验收

- 真实 item 回放成功，正文写回现有数据模型。
- Bug 记录、索引、复发根因簇同步更新。
